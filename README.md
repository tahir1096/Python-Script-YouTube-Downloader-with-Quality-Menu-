A simple yet powerful **YouTube video downloader** built with Python and `yt-dlp`.  
Choose your desired quality — **360p**, **720p**, **1080p**, or **Audio Only (MP3)** — and the script handles the rest!

---

## 🚀 Features

- 🎬 Download videos in multiple resolutions (360p, 720p, 1080p)
- 🎵 Extract **audio only (MP3)**
- 📁 Automatically creates a `downloads` folder
- ⚡ Fast and efficient using **yt-dlp**
- 💻 Simple command-line interface — beginner friendly!

---

## 🧩 Requirements

Before running the script, make sure you have:

- 🐍 **Python 3.7+**
- 📦 **yt-dlp** (install via pip)
- 🎞️ **ffmpeg** (required for merging video/audio)

---

## ⚙️ Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/Python-YouTube-Downloader.git

# 2. Navigate into the folder
cd Python-YouTube-Downloader

# 3. Install yt-dlp
pip install yt-dlp

# 4. (Optional) Install ffmpeg
# Windows: Download from https://ffmpeg.org/download.html
# Linux/macOS:
sudo apt install ffmpeg
